GET STARTED / NO ACCOUNT REQUIRED

Your browser observes.
Your workspace reviews.

Load the extension, run a local audit, and take the same report into the Windows companion. There is no sign-in or cloud account in this MVP.

01 / BROWSER

Install in Chrome or Edge

Download the project from its repository and extract it locally. Both browsers use the same extension/ folder.

chrome://extensions
edge://extensions

  1. Paste the address for your browser into its address bar.
  2. Enable Developer mode, choose Load unpacked, then select the project's extension folder.
  3. Start the local demo using the README instructions, then reload the store. Open the floating NudgeKavach launcher.
  4. On other HTTP/HTTPS pages, use the extension toolbar's Scan this page. Browser settings pages cannot be scanned.
Open Pattern Mode ↗

Reload the extension after source changes, then refresh the store. A fresh page creates a new observation baseline.

02 / WINDOWS

Move the evidence, not the page

Run NudgeKavach Desktop using the development or Windows build instructions in the repository README.

  1. In the browser panel, choose Export JSON to save NudgeProof. Keep the downloaded JSON file.
  2. Open the Windows Audit Workspace and choose Import Audit Report.
  3. Select that same file. Open an imported finding and match its ID and evidence with the browser.
  4. Export a separate Clean Control audit and import it for a Controlled Comparison.

This webpage cannot launch or inspect the Windows app. Open it locally; report transfer is a file import.
